BUILD A LIFE — Stable Classroom Edition

Stability features:
- No page reloads during gameplay.
- One-click locking prevents double scoring.
- No remote timer writes or constant screen rebuilding.
- Performance Mode disables transitions/animation effects.
- Simple DOM updates reduce flicker on school computers.
- 5-year life-stability scoring.
- College, Military, Trade/Apprenticeship, Workforce only as student-selected starting directions.
- Life assigns family circumstances, cash, savings, debt, and credit.
- Includes housing, transportation, car insurance, health insurance, childcare/family care, medical expenses, credit, debt, career development and emergencies.

This package is the stable standalone classroom foundation. Firebase multiplayer should use instructor-authoritative state, transactions for first-choice locking, reconnect persistence, and a read-only scoreboard.
